# homecare

A modern healthcare platform built with Next.js.

## Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open `http://localhost:3000` in your browser to view the application.

You can start editing the app by modifying files inside the `app/` directory. Changes update automatically during development.

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS

## Project Structure

```bash
app/          # Application routes and pages
components/   # Reusable UI components
lib/          # Utilities and helpers
public/       # Static assets
styles/       # Global styles
```

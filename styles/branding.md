# HEARD Home Care - Brand Guidelines

## Brand Summary
Client-provided brand guidelines for the HEARD Home Care website project.

## Colors

| Color Name | Hex Code | Usage |
|------------|----------|-------|
| Primary Purple | `#332885` | Main brand color - buttons, headings, accents |
| Black | `#000000` | Text, backgrounds, contrast elements |
| White | `#ffffff` | Text on dark backgrounds, cards, negative space |
| Light Lavender | `#f3f0ff` | Secondary background, subtle highlights |

## Typography

| Element | Font | Notes |
|---------|------|-------|
| Headings | Gantari | Bold, clean sans-serif for modern feel |
| Body | Gantari | Readable, accessible text |

## Usage Notes
- Always use `#332885` for primary brand elements
- Avoid using blue tones - stick to purple/black/white
- Use light lavender (`#f3f0ff`) for complementary backgrounds
- Gantari font should be used for all text elements

## Brand Colors (CSS Variables)
```css
:root {
  --brand-purple: #332885;
  --brand-black: #000000;
  --brand-white: #ffffff;
  --brand-light: #f3f0ff;
}
```
